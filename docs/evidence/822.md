# Evidence #822: coalesce dca_guard skip events (N = 2) and dedupe DCA reflector lessons

Base commit: `a1508cc` (origin/staging). Measured with the in-memory store and an
in-memory RAG retriever (hash embeddings, no Weaviate), same scenario on both sides:
30 older market events for one synthetic symbol, one `volume_breakout` event at
minute 5:30, then 40 identical `dca_guard_below_avg` skips (one every 90 s for one
hour) for tenant `henry`. After every skip the DCA reflector (`min_events=5`) and
the cycle RAG indexer (`index_store_into_rag`) run, as in the memory cycle.

| metric | before | after |
|--------|--------|-------|
| DCA skip rows among the last 40 events for the symbol (fact window) | 39 | 2 |
| skip count stored on the rolling event | none | 40 |
| `first_ts` / `last_ts` stored | no | yes |
| `volume_breakout` from the same hour in the 40-event window | yes (last slot) | yes |
| live "skipped add-ons often" lessons in `memory_lessons` | 1 | 1 |
| "skipped add-ons often" RAG chunks (5, 6, 7, ... clones) | 36 | 1 |
| RAG chunks for the DCA skip events | 40 | 2 |
| guard decision for a lot below average (`evaluate_dca_guard`) | blocked, `dca_guard_below_avg` | blocked, `dca_guard_below_avg` |

## What changed

- `strategies/dca_decision_event.py`: skip decisions (`result.skip=True`) use two
  deterministic slots per tenant, symbol, applied path and reason set
  (`SKIP_EVENTS_PER_LOT = 2`, code default, N = 2 decided by Kay): `first` keeps
  the first skip, `latest` is upserted with `count`, `first_ts`, `last_ts`. The
  tenant id is in the slot key and the stored row (#721). Non-skip decisions keep
  one row each with the old per-timestamp id. A store error in the coalesce path
  is logged and writes nothing; it never falls back to one row per skip.
- `intelligence/memory/rag_store.py`: `chunk_id_for` honours an optional
  `chunk_key` in the metadata, so an in-place record gets one chunk that is
  replaced when its text changes.
- `intelligence/memory/rag_index.py`: the cycle indexer sets `chunk_key` for
  DCA reflector lessons and coalesced DCA skip events.
- `intelligence/memory/dca_reflector.py`: skip rows are weighted by their stored
  count (no double count of the `first` slot), so the per-symbol lesson still
  fires and still reports the real number of skips; its RAG chunk uses the stable
  lesson id as `chunk_key`.

No change to the guard, the policy result, sizing, order flow, `config.json`,
tenant config, `*.live.json`, `risk/`, `execution/` or `aria_bot.py`.

## Known limits

- Lot identity: positions carry no lot id, so the family key is per tenant and
  symbol (one open spot lot per symbol per book). A later lot on the same symbol
  with the same reason set keeps updating the same two rows; `first_ts` then
  belongs to the earlier lot.
- RAG chunks written before this change (old 5/6/7/... clones and per-skip event
  chunks) are not deleted by this PR.

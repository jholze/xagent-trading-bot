# Evidence: hard-stop partials become one full sell

Money-path change (exits). The owner decides. This file does not add `owner-approved`.

A locked `partial_sell_guard` reject (`min_position`, `min_notional`, or a missing sold-cap key) of an order that carries `TradeOrder.hard_stop_origin` becomes one `SELL_STOP_FULL` for that lot. The marker is set only for a WebSocket `exit_source=stop_loss` and for the cycle `long_hard_stop`. A plain stop label, worker, recovery, manual, and DCA shapes stay rejected. Locks and a configured sold cap still block. The daily-sell cap is bypassed only on that marked path, and only when price is strictly below the lot's `average_entry`. A missing or zero entry fails closed.

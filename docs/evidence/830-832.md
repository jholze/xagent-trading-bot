## Semantics to confirm (owner)

- **Cycle paths now differ on a stale quote for a tagged short.**
  - With the eval queue on (#826, `process_eval_job`), `price_source="stale"` reaches `evaluate_short_cover`, which returns the #809 unpriced cover. The cover is sent.
  - The hub (#826) and now the queue-off loop (#832) defer instead and count `stale_tagged_short_deferred`.
  - #832 asked for deferral. The eval-queue path is unchanged here. If both cycle paths should behave the same, that is a separate decision.
- **Read-intent proof.** A recovery read places no risk, so it does not set margin. The read proof is: adapter mode and resolved execution mode are both `testnet`, and ccxt `isSandboxModeEnabled is True`.
- **Freshness.** Set and readback are stamped with the local clock when the response arrives, and `observed_at` is taken after both. The Gate position payload has no server time, so `clock_skew_seconds` is not applied. Both stamps come from the same clock.

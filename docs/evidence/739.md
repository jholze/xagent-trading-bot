# Evidence: cycle silence and the auto-order watchdog

Money-path change. This branch is stacked on #738, so the diff against `staging` includes the hard-stop full sell as well as the cycle-silence fix. The owner decides. This file does not add `owner-approved`.

A held lot that is already through the hard stop gets one `source=auto` stop from the cycle merge, instead of the entry queue replacing that check with HOLD. Heartbeat jobs are kept when the queue is trimmed. The watchdog alarms when a tenant has no `source=auto` order for N cycles. N is not a literal in code. `config.json` sets `observability.cycle_watchdog.auto_silent_cycles` and `fill_silent_cycles` to 60 (`ceil(7200 / update_interval 120)`). A tenant body can override both. Missing or invalid N raises one `watchdog_unconfigured` alarm and does not guess. 60 cycles is at least two hours, because a real cycle can run longer than 120 seconds.

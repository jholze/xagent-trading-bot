# Evidence: per-tenant config snapshot and position debounce

Money-path change. `strategies/positions.py` and `strategies/dca_decision_event.py` are on the money-path list. The owner decides. This file does not add `owner-approved`.

A shared `BotConfig` keeps one snapshot per tenant. `refresh()` no longer replaces a process-global document another thread is reading. After `refresh()` has run, a reader inside `tenant_context` with no snapshot for that tenant does not receive the previous tenant's fallback. A non-dict or a failed load logs ERROR and raises. Position debounce timers are keyed by `(tenant, scope)`. Market memory events are stamped `global`; DCA decision events stay on the calling tenant.

No production tenant overlay was read for this change. The four-week export does not include Mongo tenant config bodies, so no live cap or stop difference is claimed.

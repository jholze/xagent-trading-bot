# Evidence for PR #834: Buy & Hold benchmark starts at cash (#827)

Harness-only, no money path. Implemented by **claude-opus-5-5** (Claude Code). Reviewer: claude-opus-5-5 (separate Omnigent session).

## Change
`backtest/harness/benchmark.py::buy_and_hold()` now starts the B&H series at cash. The first point, and any point before the entry bar opens, is worth `per_leg`. Every later mark is unchanged (liquidation value net of fee + slippage). Before, `equity[0]` already had the round-trip cost netted in, so `series_metrics()` cancelled the cost out of return, PnL, the first month and the first daily return. The strategy series is unchanged.
